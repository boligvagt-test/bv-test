# Boligvagt

A notification on your phone within a few minutes when a rental home in Copenhagen
that fits you appears. Watches Boligportal, Findbolig, CEJ, Kereby,
Lejeboligmægleren, Norhjem, Capital Bolig, C.W. Obel, Taurus, Juli Living and
City Apartment. Runs for free on GitHub and sends notifications through Pushover.

- **[START-HERE.md](START-HERE.md)** – if someone runs Boligvagt for you (10 min)
- **[SETUP.md](SETUP.md)** – how to set it up yourself (about 30 min)
- **[MESSAGE-TEMPLATE.md](MESSAGE-TEMPLATE.md)** – your message to the landlord
- **[GOOD-TO-KNOW.md](GOOD-TO-KNOW.md)** – Danish housing words, which accounts can be closed, prices, non-profit housing
- **[settings.toml](settings.toml)** – your search settings

For Simon (Danish): [DECISIONS.md](DECISIONS.md) – hvad der er valgt og hvorfor.

Code for CEJ, Kereby and City Apartment and for automatic contact builds on
[arminpasalic/boligvagten](https://github.com/arminpasalic/boligvagten) (MIT).
The Boligportal method is from [nille/boligwatch](https://github.com/nille/boligwatch) (MIT).
The licences are in [LICENSES.md](LICENSES.md).
